# Modern Tic Tac Toe

A modern Tic Tac Toe game built with HTML, CSS, and JavaScript featuring animated gameplay, AI opponent logic, responsive design, and multiple visual themes.

## Features

- Player vs Player mode
- Player vs AI mode
- Minimax AI algorithm
- Animated SVG X and O rendering
- Responsive layout
- Dark, Light, and Neon themes
- Score tracking
- Confetti win animations
- Accessibility support
- Smooth UI animations and transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
